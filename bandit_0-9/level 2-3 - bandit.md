# Task
#### Find the password for the next level, which located in a file call - located in the home directory
- Password found in the previous level: PK8fYLZg2hnHSz83plBL1iEPKdD3QToB
# Solution
- Like the previous level, we first use the command ``` ls -la ``` to view all the files in the folder.
- We can see that there is a file name ```--spaces in this file name--```
- This filename contain not only```-```, but also a spaces between the name. To deal with it, we can use ```./``` and ```\``` in our command, which look something like this
```cat ./--spaces\ in\ this\ filename--```
